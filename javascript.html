🚀 1. Introduction to JavaScript Getting Started

JavaScript is a lightweight, interpreted programming language that runs in every modern browser. Along with HTML and CSS, it is one of the three core technologies of the web, responsible for interactivity and dynamic behavior.

Where can JavaScript run?
  • Inside the browser (client-side) for interactivity
  • On servers using Node.js (back-end)
  • In mobile apps, desktop apps and even IoT devices
console.log("Hello, JavaScript!");
// Add this inside a <script> tag or a .js file linked with <script src="app.js"></script>
Output:
Hello, JavaScript!

📦 2. Variables: var, let & const Core Concepts

Variables store data values. JavaScript offers three ways to declare them, each with different scoping rules.

var oldStyle = "function-scoped";
let counter = 10;        // block-scoped, reassignable
const pi = 3.14159;      // block-scoped, cannot be reassigned

counter = 20;            // OK
// pi = 3;               // Error! Cannot reassign a const
Best Practice: Prefer const by default, and only use let when the value needs to change. Avoid var in modern code.

🧬 3. Data Types Values & Types

JavaScript has primitive types (string, number, boolean, null, undefined, symbol, bigint) and reference types (object, array, function).

let name = "SyntaxLab";     // string
let count = 42;             // number
let price = 19.99;          // number (no separate float type)
let isActive = true;        // boolean
let empty = null;           // null
let notSet;                 // undefined
let user = { name: "Sam" }; // object
let list = [1, 2, 3];       // array (a special object)

console.log(typeof count, typeof name, typeof user);
Output:
number string object

🧮 4. Operators Expressions

Arithmetic, comparison, logical and ternary operators let you build expressions and make decisions.

let sum = 10 + 5;              // arithmetic
let strictEqual = (10 === "10");  // false: checks type too
let looseEqual  = (10 == "10");   // true: converts type first
let isAdult = (18 >= 18) ? "Yes" : "No";  // ternary

if (true && !false) {
  console.log("Logical AND / NOT works");
}
Output:
Logical AND / NOT works

🔄 5. Control Flow if / else / switch

Control the path your program takes using conditionals.

let score = 82;

if (score >= 90) {
  console.log("Grade A");
} else if (score >= 70) {
  console.log("Grade B");
} else {
  console.log("Grade C");
}

switch (new Date().getDay()) {
  case 0: console.log("Sunday"); break;
  case 6: console.log("Saturday"); break;
  default: console.log("Weekday");
}
Output:
Grade B

🔁 6. Loops for / while / do-while

Loops repeat a block of code while a condition holds true.

for (let i = 0; i < 3; i++) {
  console.log("for loop:", i);
}

let i = 0;
while (i < 3) {
  console.log("while loop:", i);
  i++;
}

for (const fruit of ["apple", "mango"]) {
  console.log("for...of:", fruit);
}
Output:
for loop: 0 for loop: 1 for loop: 2 ...

⚙️ 7. Functions Reusable Code

Functions bundle reusable logic. They can take parameters, return values, and even have default parameters.

function greet(name = "Guest") {
  return `Hello, ${name}!`;
}

console.log(greet("Riya"));
console.log(greet());

function sum(...numbers) {   // rest parameters
  return numbers.reduce((a, b) => a + b, 0);
}
console.log(sum(1, 2, 3, 4));
Output:
Hello, Riya! Hello, Guest! 10

🏹 8. Arrow Functions Concise Syntax

Arrow functions provide a shorter syntax and do not rebind this, which is useful inside callbacks.

const add = (a, b) => a + b;
const square = n => n * n;
const sayHi = () => console.log("Hi!");

console.log(add(4, 5));
console.log(square(6));
Output:
9 36

📚 9. Arrays Ordered Lists

Arrays store ordered collections of values and come with many built-in helper methods.

let fruits = ["apple", "banana", "orange"];
fruits.push("grape");        // add to end
fruits.shift();              // remove from start
console.log(fruits.length, fruits.includes("grape"));
console.log(fruits.join(", "));
Output:
3 true banana, orange, grape

🧰 10. Array Methods: map, filter, reduce Functional Style

These three methods are the workhorses of modern JavaScript for transforming data without writing manual loops.

const nums = [1, 2, 3, 4, 5];

const doubled = nums.map(n => n * 2);
const evens   = nums.filter(n => n % 2 === 0);
const total   = nums.reduce((acc, n) => acc + n, 0);

console.log(doubled);
console.log(evens);
console.log(total);
Output:
[2, 4, 6, 8, 10] [2, 4] 15

🧱 11. Objects Key-Value Data

Objects store structured data as key-value pairs and can also hold methods.

const user = {
  name: "SyntaxMaster",
  age: 25,
  greet() {
    return `Hi, I am ${this.name}`;
  }
};

console.log(user.name);
console.log(user["age"]);
console.log(user.greet());
Output:
SyntaxMaster 25 Hi, I am SyntaxMaster

🎁 12. Destructuring & Spread Modern Syntax

Destructuring pulls values out of arrays/objects into variables; the spread operator expands them back out.

const user = { name: "Sam", age: 30, city: "Delhi" };
const { name, city } = user;
console.log(name, city);

const nums = [1, 2, 3];
const copy = [...nums, 4, 5];
console.log(copy);

const merged = { ...user, age: 31 };
console.log(merged.age);
Output:
Sam Delhi [1, 2, 3, 4, 5] 31

🎯 13. DOM Manipulation Interacting with HTML

The Document Object Model (DOM) lets JavaScript read and change the page after it has loaded.

const heading = document.querySelector("h1");
heading.textContent = "Hello JavaScript!";

const newItem = document.createElement("li");
newItem.textContent = "New list item";
document.querySelector("ul").appendChild(newItem);
Tip: Always wait for DOMContentLoaded before querying elements, or place your script tag at the end of the body.

🎪 14. Events Clicks, Input & More

Event listeners let your page react to user actions such as clicks, keystrokes and form submissions.

const button = document.getElementById("myButton");
button.addEventListener("click", () => {
  alert("Button clicked!");
});

document.getElementById("nameInput").addEventListener("input", (e) => {
  console.log("Typed:", e.target.value);
});

☁️ 15. Promises & Async/Await Asynchronous JS

Promises represent a value that will be available later. async/await makes asynchronous code read like synchronous code.

function delay(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

async function run() {
  console.log("Start");
  await delay(1000);
  console.log("1 second later");
}

run();
Output:
Start (1 second later)

🌐 16. Fetch API & JSON Talking to Servers

The Fetch API is used to make network requests to APIs and servers, usually returning JSON data.

async function getUsers() {
  try {
    const response = await fetch("https://api.example.com/users");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Request failed:", error);
  }
}

getUsers();

✨ 17. Template Literals & ES6+ Modern Features

Template literals (backticks) allow embedded expressions and multi-line strings, one of many ES6+ upgrades to the language.

const name = "SyntaxLab";
const version = 2;

const message = `Welcome to ${name} v${version}!
Enjoy learning JavaScript.`;

console.log(message);

🛡️ 18. Error Handling try / catch / finally

Use try/catch to gracefully handle runtime errors instead of letting the whole script crash.

try {
  const data = JSON.parse("{ invalid json }");
} catch (error) {
  console.log("Caught an error:", error.message);
} finally {
  console.log("This always runs.");
}
Output:
Caught an error: ... This always runs.
