🗄️ 1. Database Basics Getting Started

SQL (Structured Query Language) is used to communicate with relational databases. Databases store organized data in tables of rows and columns.

-- Create a database
CREATE DATABASE company;

-- Use the database
USE company;

-- Create a table
CREATE TABLE employees (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    salary DECIMAL(10,2)
);

📝 2. CREATE & INSERT Adding Data

Create tables with CREATE TABLE and add rows with INSERT INTO.

CREATE TABLE products (
    product_id INT PRIMARY KEY,
    product_name VARCHAR(255),
    price DECIMAL(10,2)
);

INSERT INTO products (product_id, product_name, price)
VALUES (1, 'Laptop', 999.99),
       (2, 'Mouse', 29.99);

🔍 3. SELECT Statement Reading Data

Retrieve data from database tables with SELECT.

-- Select all columns
SELECT * FROM employees;

-- Select specific columns
SELECT name, salary FROM employees;

-- Select with alias
SELECT name AS employee_name, salary FROM employees;

🎯 4. WHERE Clause Filtering Rows

Filter records based on one or more conditions.

SELECT * FROM employees WHERE department = 'IT';

SELECT * FROM products WHERE price > 50;

SELECT * FROM employees
WHERE age >= 25 AND salary > 50000;

SELECT * FROM customers WHERE name LIKE 'J%';

📊 5. ORDER BY & GROUP BY Sorting & Aggregation

Sort results with ORDER BY and group rows for aggregation with GROUP BY.

SELECT name, salary FROM employees
ORDER BY salary DESC;

SELECT department, COUNT(*) AS emp_count, AVG(salary) AS avg_salary
FROM employees
GROUP BY department
HAVING AVG(salary) > 60000;

🔗 6. JOIN Operations Combining Tables

Combine data from multiple related tables using INNER, LEFT, RIGHT or FULL joins.

SELECT employees.name, departments.dept_name
FROM employees
INNER JOIN departments ON employees.dept_id = departments.id;

SELECT customers.name, orders.order_date
FROM customers
LEFT JOIN orders ON customers.id = orders.customer_id;

✏️ 7. UPDATE & DELETE Modifying Data

Modify existing rows with UPDATE, or remove them with DELETE.

UPDATE employees
SET salary = salary * 1.10
WHERE department = 'Sales';

DELETE FROM employees
WHERE status = 'inactive';
-- Always use WHERE with DELETE, or you'll remove every row!

📈 8. Subqueries & Views Advanced Queries

A subquery nests one query inside another; a view saves a query as a reusable virtual table.

SELECT name, salary
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);

CREATE VIEW high_earners AS
SELECT name, salary, department
FROM employees
WHERE salary > 75000;

🔑 9. Constraints & Keys Data Integrity

Constraints enforce rules on data: PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL.

CREATE TABLE orders (
    order_id INT PRIMARY KEY,
    customer_id INT NOT NULL,
    quantity INT CHECK (quantity > 0),
    FOREIGN KEY (customer_id) REFERENCES customers(id)
);

🧮 10. Aggregate Functions COUNT, SUM, AVG

Aggregate functions compute a single value from a set of rows.

SELECT COUNT(*) AS total_employees,
       SUM(salary) AS total_payroll,
       MAX(salary) AS highest_salary,
       MIN(salary) AS lowest_salary
FROM employees;

🏷️ 11. ALTER & DROP Modifying Structure

Change table structure with ALTER TABLE, or remove tables entirely with DROP TABLE.

ALTER TABLE employees ADD COLUMN email VARCHAR(100);
ALTER TABLE employees DROP COLUMN age;

DROP TABLE IF EXISTS temp_table;

🚀 12. Indexes Query Optimization

Indexes speed up data retrieval at the cost of extra storage and slower writes.

CREATE INDEX idx_lastname ON customers(last_name);

-- Composite index on two columns
CREATE INDEX idx_dept_salary ON employees(department, salary);

🔀 13. UNION & Set Operations Combining Results

UNION combines the results of two queries, removing duplicates by default.

SELECT name FROM employees
UNION
SELECT name FROM contractors;

-- UNION ALL keeps duplicates and is faster
SELECT city FROM customers
UNION ALL
SELECT city FROM suppliers;

🧩 14. Transactions COMMIT & ROLLBACK

Transactions group multiple statements so they all succeed together or none apply, keeping data consistent.

BEGIN TRANSACTION;

UPDATE accounts SET balance = balance - 500 WHERE id = 1;
UPDATE accounts SET balance = balance + 500 WHERE id = 2;

COMMIT;
-- Use ROLLBACK; instead of COMMIT; to undo on error
