🚀 1. Introduction to C++ Getting Started

C++ extends C with object-oriented features. It's used for system software, game engines, and performance-critical applications.

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!" << endl;
    return 0;
}
Output:
Hello, C++!

📦 2. Variables & Data Types Values & Types

C++ supports primitive, derived and user-defined data types, plus the string class.

int age = 25;
double price = 99.99;
char letter = 'A';
bool isValid = true;
string name = "SyntaxLab";

cout << name << " is " << age << endl;
Output:
SyntaxLab is 25

🧮 3. Operators Expressions

C++ supports the same operator families as C, plus operator overloading for custom types.

int a = 10, b = 3;
cout << a + b << " " << a % b << " " << (a > b) << endl;

⚖️ 4. Control Flow if / else / switch

Conditional statements direct the flow of your program.

int score = 75;

if (score >= 90) cout << "A";
else if (score >= 70) cout << "B";
else cout << "C";
Output:
B

🔄 5. Loops for / while / do-while

Repeat code with for, while, do-while, and the range-based for loop.

for (int i = 0; i < 3; i++) cout << i << " ";

int arr[] = {1, 2, 3};
for (int n : arr) cout << n << " ";

⚙️ 6. Functions Reusable Code

Functions can be overloaded (same name, different parameter types) and support default arguments.

int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }

int main() {
    cout << add(2, 3) << " " << add(2.5, 1.5);
    return 0;
}
Output:
5 4

🏗️ 7. Classes & Objects (OOP) Encapsulation

Classes encapsulate data and functions together. Objects are instances of classes.

class Car {
public:
    string brand;
    void drive() {
        cout << brand << " is driving" << endl;
    }
};

int main() {
    Car myCar;
    myCar.brand = "Tesla";
    myCar.drive();
    return 0;
}
Output:
Tesla is driving

🌳 8. Inheritance Extending Classes

Derived classes inherit properties and methods from base classes using : public.

class Vehicle {
public:
    void honk() { cout << "Beep beep!" << endl; }
};

class Car : public Vehicle {
public:
    string model;
};

Car myCar;
myCar.honk();
Output:
Beep beep!

🎨 9. Polymorphism Virtual Functions

Virtual functions let derived classes override base class behavior, resolved at runtime.

class Animal {
public:
    virtual void sound() { cout << "Animal makes sound" << endl; }
};

class Dog : public Animal {
public:
    void sound() override { cout << "Dog barks" << endl; }
};

Animal* a = new Dog();
a->sound();
Output:
Dog barks

🧩 10. Abstract Classes Pure Virtual Functions

An abstract class has at least one pure virtual function (= 0) and cannot be instantiated directly.

class Shape {
public:
    virtual double area() = 0;   // pure virtual
};

class Circle : public Shape {
    double r;
public:
    Circle(double r) : r(r) {}
    double area() override { return 3.14159 * r * r; }
};

📊 11. Vectors & STL Standard Template Library

The STL provides dynamic arrays, algorithms, and generic containers like vector, map and set.

#include <vector>
#include <algorithm>

vector<int> numbers = {5, 2, 8, 1};
sort(numbers.begin(), numbers.end());

for (int num : numbers) cout << num << " ";
Output:
1 2 5 8

🧠 12. Pointers & References Memory Management

Pointers store addresses; references are aliases for existing variables and cannot be null or reassigned.

int x = 10;
int *ptr = &x;
int &ref = x;

*ptr = 20;
ref = 30;
cout << x;
Output:
30

⚠️ 13. Exception Handling try / catch

Handle runtime errors gracefully using try-catch blocks and the exception hierarchy.

try {
    int age = -5;
    if (age < 0) throw invalid_argument("Age cannot be negative");
} catch (const exception& e) {
    cout << "Error: " << e.what() << endl;
}
Output:
Error: Age cannot be negative

📄 14. File I/O fstream

Read from and write to files using the fstream library.

#include <fstream>

ofstream outFile("data.txt");
outFile << "Hello, File!" << endl;
outFile.close();

ifstream inFile("data.txt");
string line;
while (getline(inFile, line)) cout << line << endl;

🧬 15. Templates Generic Programming

Templates let you write functions and classes that work with any data type.

template <typename T>
T maxVal(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << maxVal(3, 7) << " " << maxVal(2.5, 1.2);
    return 0;
}
Output:
7 2.5
