☕ 1. Introduction to Java Getting Started

Java is a versatile, object-oriented programming language used for web, mobile (Android) and enterprise applications. Code compiles to bytecode and runs on the Java Virtual Machine (JVM).

Why Java?
  • Platform-independent: "write once, run anywhere"
  • Strongly typed and object-oriented
  • Huge ecosystem for enterprise & Android apps
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
Output:
Hello, Java!

📦 2. Variables & Data Types Values & Types

Java is strongly typed. Every variable must be declared with a primitive or reference type.

int age = 25;
double price = 19.99;
char grade = 'A';
boolean isActive = true;
String name = "SyntaxLab";

System.out.println(name + " - " + age);
Output:
SyntaxLab - 25

🧮 3. Operators Expressions

Java supports arithmetic, relational, logical and assignment operators.

int a = 10, b = 3;
System.out.println(a + b);
System.out.println(a % b);
System.out.println(a > b && b > 0);

⚖️ 4. Control Flow if / else / switch

Use conditionals to control which code executes.

int score = 82;

if (score >= 90) {
    System.out.println("Grade A");
} else if (score >= 70) {
    System.out.println("Grade B");
} else {
    System.out.println("Grade C");
}
Output:
Grade B

🔁 5. Loops for / while / do-while

Java supports the classic loop constructs, plus the enhanced for-each loop.

for (int i = 0; i < 3; i++) {
    System.out.println("i = " + i);
}

int[] nums = {10, 20, 30};
for (int n : nums) {
    System.out.println(n);
}

🧱 6. Arrays Fixed-size Collections

Arrays store a fixed number of elements of the same type.

int[] numbers = {1, 2, 3, 4, 5};
System.out.println(numbers.length);
System.out.println(numbers[2]);

int[][] grid = { {1, 2}, {3, 4} };
System.out.println(grid[1][0]);
Output:
5 3 3

🔤 7. Strings Text Handling

The String class provides many methods for text processing.

String s = "SyntaxLab";
System.out.println(s.toUpperCase());
System.out.println(s.length());
System.out.println(s.substring(0, 6));

⚙️ 8. Methods Reusable Code Blocks

Methods define reusable behavior and can be overloaded (same name, different parameters).

static int add(int a, int b) {
    return a + b;
}

static double add(double a, double b) {
    return a + b;
}

public static void main(String[] args) {
    System.out.println(add(2, 3));
    System.out.println(add(2.5, 3.5));
}
Output:
5 6.0

🏗️ 9. Classes & Objects OOP Basics

Classes are blueprints for objects. Encapsulation uses private fields with public getters/setters.

public class Student {
    private String name;
    private int age;

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void display() {
        System.out.println(name + " is " + age);
    }
}

Student s1 = new Student("John", 20);
s1.display();
Output:
John is 20

🌳 10. Inheritance extends

A subclass inherits fields and methods from a parent class using extends.

class Vehicle {
    void start() {
        System.out.println("Vehicle started");
    }
}

class Car extends Vehicle {
    void drive() {
        System.out.println("Car is driving");
    }
}

Car c = new Car();
c.start();
c.drive();
Output:
Vehicle started Car is driving

🎭 11. Polymorphism Method Overriding

Subclasses can override parent methods to provide their own implementation.

class Animal {
    void sound() { System.out.println("Animal makes a sound"); }
}

class Dog extends Animal {
    @Override
    void sound() { System.out.println("Dog barks"); }
}

Animal a = new Dog();
a.sound();
Output:
Dog barks

🧩 12. Abstraction & Interfaces Contracts

Interfaces define a contract of methods that implementing classes must provide.

interface Drawable {
    void draw();
}

class Circle implements Drawable {
    public void draw() {
        System.out.println("Drawing circle");
    }
}

new Circle().draw();
Output:
Drawing circle

⚠️ 13. Exception Handling try / catch / finally

Handle runtime errors using try-catch-finally so the program doesn't crash unexpectedly.

try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Cannot divide by zero!");
} finally {
    System.out.println("This always executes");
}
Output:
Cannot divide by zero! This always executes

📚 14. Collections Framework ArrayList & HashMap

The Collections Framework provides ready-made dynamic data structures like ArrayList and HashMap.

import java.util.*;

ArrayList<String> list = new ArrayList<>();
list.add("Java");
list.add("Python");

HashMap<String, Integer> map = new HashMap<>();
map.put("One", 1);
map.put("Two", 2);

System.out.println(list);
System.out.println(map.get("One"));
Output:
[Java, Python] 1

🧵 15. Multithreading Concurrent Execution

Run multiple tasks concurrently using the Thread class or Runnable interface.

class MyThread extends Thread {
    public void run() {
        System.out.println("Thread running");
    }
}

new MyThread().start();

Runnable task = () -> System.out.println("Runnable task");
new Thread(task).start();

📄 16. File Handling Reading & Writing Files

Read and write files using FileWriter, FileReader and BufferedReader.

import java.io.*;

FileWriter writer = new FileWriter("data.txt");
writer.write("Hello Java!");
writer.close();

BufferedReader reader = new BufferedReader(new FileReader("data.txt"));
System.out.println(reader.readLine());

🧬 17. Generics Type-Safe Code

Generics let classes and methods operate on typed parameters, catching type errors at compile time.

class Box<T> {
    private T value;
    public void set(T value) { this.value = value; }
    public T get() { return value; }
}

Box<Integer> intBox = new Box<>();
intBox.set(10);
System.out.println(intBox.get());
Output:
10

🚀 18. Java 8+ Features: Lambdas & Streams Modern Java

Lambda expressions and the Stream API enable a concise, functional style of processing collections.

import java.util.*;
import java.util.stream.*;

List<Integer> nums = List.of(1, 2, 3, 4, 5);
int sum = nums.stream()
              .filter(n -> n % 2 == 0)
              .mapToInt(Integer::intValue)
              .sum();

System.out.println(sum);
Output:
6
