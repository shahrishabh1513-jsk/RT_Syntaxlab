🐍 1. Introduction to Python Getting Started

Python is a high-level, interpreted, general-purpose language known for its clean, readable syntax. It powers web apps, data science, automation, AI and much more.

Why Python?
  • Simple, English-like syntax — great for beginners
  • Huge ecosystem: Django, Flask, NumPy, Pandas, TensorFlow
  • Runs on Windows, macOS and Linux
# This is a comment
print("Hello, Python!")
Output:
Hello, Python!

📦 2. Variables & Data Types Values & Types

Python is dynamically typed — you don't declare a type, it's inferred automatically from the value.

age = 25                 # int
price = 19.99             # float
language = "Python"       # str
is_awesome = True         # bool

print(type(age))
print(f"{language} costs ${price}")
Output:
<class 'int'> Python costs $19.99

🧮 3. Operators Expressions

Python supports arithmetic, comparison, logical and membership operators.

a, b = 10, 3
print(a + b, a // b, a ** 2)   # + - * / // (floor div) ** (power)
print(a > b and b > 0)
print(5 in [1, 3, 5, 7])

⚖️ 4. Control Flow if / elif / else

Python uses indentation (not braces) to define code blocks.

score = 85

if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"

print(f"Your grade is {grade}")
Output:
Your grade is B

🔄 5. Loops for / while

Iterate over sequences with for, or repeat while a condition holds with while.

for fruit in ["apple", "banana", "orange"]:
    print(fruit)

for i in range(3):
    print(f"Count: {i}")

count = 0
while count < 3:
    print("while:", count)
    count += 1

⚙️ 6. Functions Reusable Code

Functions are defined with def and can take default and keyword arguments.

def greet(name="Guest"):
    return f"Hello, {name}!"

print(greet("Python Learner"))
print(greet())

def power(base, exp=2):
    return base ** exp

print(power(3))
Output:
Hello, Python Learner! Hello, Guest! 9

📊 7. Lists Ordered, Mutable

Lists store ordered, changeable collections and support slicing and comprehensions.

colors = ["red", "green", "blue"]
colors.append("yellow")
colors.remove("green")

squares = [x**2 for x in range(5)]  # list comprehension
print(colors)
print(squares)
print(colors[0:2])   # slicing
Output:
['red', 'blue', 'yellow'] [0, 1, 4, 9, 16] ['red', 'blue']

🔑 8. Dictionaries Key-Value Pairs

Dictionaries store data as key-value pairs, ideal for structured, labeled data.

person = {"name": "John", "age": 30, "city": "New York"}
person["email"] = "john@example.com"

for key, value in person.items():
    print(key, "->", value)

📐 9. Tuples & Sets Immutable & Unique

Tuples are ordered and immutable; sets store unique, unordered items.

point = (10, 20)          # tuple - cannot be changed
x, y = point              # unpacking

unique_nums = {1, 2, 2, 3, 3, 3}
print(x, y)
print(unique_nums)
Output:
10 20 {1, 2, 3}

🧵 10. Strings Text Handling

Strings support slicing, formatting and many built-in methods.

name = "syntaxlab"
print(name.upper())
print(name.capitalize())
print(name[0:6])
print(f"Length: {len(name)}")
Output:
SYNTAXLAB Syntaxlab syntax Length: 9

📄 11. File Handling Reading & Writing

Use with open(...) so files are closed automatically, even if an error occurs.

with open("data.txt", "w") as file:
    file.write("Hello Python!\n")

with open("data.txt", "r") as file:
    content = file.read()
    print(content)

⚠️ 12. Exception Handling try / except / finally

Handle runtime errors gracefully instead of crashing the whole program.

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero!")
else:
    print("No errors occurred")
finally:
    print("This always runs")
Output:
Cannot divide by zero! This always runs

🏗️ 13. Object-Oriented Programming Classes & Objects

Classes are blueprints for objects, bundling data (attributes) and behavior (methods).

class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

    def display(self):
        return f"{self.name} scored {self.grade}"

student1 = Student("Alice", "A")
print(student1.display())
Output:
Alice scored A

🌳 14. Inheritance Extending Classes

A subclass inherits attributes and methods from its parent class using super().

class Student:
    def __init__(self, name):
        self.name = name

class GraduateStudent(Student):
    def __init__(self, name, thesis):
        super().__init__(name)
        self.thesis = thesis

g = GraduateStudent("Meera", "AI Ethics")
print(g.name, "-", g.thesis)
Output:
Meera - AI Ethics

🧩 15. Modules & Packages Code Organization

Modules let you split code across files and reuse built-in or third-party functionality.

import math
from datetime import date

print(math.sqrt(16))
print(date.today())
Output:
4.0 2026-09-20

🎯 16. Lambda & Comprehensions Functional Style

Lambdas are small anonymous functions; comprehensions build lists/dicts in a single readable line.

square = lambda x: x * x
print(square(5))

nums = [1, 2, 3, 4, 5]
even_squares = [n*n for n in nums if n % 2 == 0]
print(even_squares)
Output:
25 [4, 16]

📦 17. Virtual Environments & pip Package Management

Use virtual environments to isolate project dependencies, and pip to install packages.

# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate     # macOS/Linux
venv\Scripts\activate        # Windows

# Install a package
pip install requests

The popular requests library makes it easy to call web APIs and work with JSON data.

import requests

response = requests.get("https://api.example.com/users")
data = response.json()
print(data)
