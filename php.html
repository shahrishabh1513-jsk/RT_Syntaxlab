🐘 1. Introduction to PHP Getting Started

PHP is a widely-used, open-source, server-side scripting language designed for web development. PHP code runs on the server and outputs plain HTML to the browser.

<?php
// This is a PHP comment
echo "Hello, World!";
?>
Output:
Hello, World!

📊 2. Variables & Data Types Values & Types

PHP variables start with a $ sign and are loosely typed.

<?php
$name = "SyntaxLab";
$age = 5;
$price = 29.99;
$isActive = true;

echo "Name: " . $name;
?>
Output:
Name: SyntaxLab

🧮 3. Operators Expressions

PHP supports arithmetic, comparison, logical, and the string concatenation (.) operator.

<?php
$a = 10; $b = 3;
echo $a + $b;
echo "<br>";
echo $a . " items";   // concatenation
echo "<br>";
var_dump($a == "10", $a === "10");
?>

⚖️ 4. Conditional Statements if / elseif / switch

Control program flow with if, elseif, else and switch statements.

<?php
$score = 85;

if ($score >= 90) {
    echo "Grade A";
} elseif ($score >= 70) {
    echo "Grade B";
} else {
    echo "Need improvement";
}
?>
Output:
Grade B

🔄 5. Loops for / while / foreach

Repeat code blocks with for, while and foreach loops.

<?php
for ($i = 0; $i < 5; $i++) {
    echo $i . "<br>";
}

$colors = ["red", "green", "blue"];
foreach ($colors as $color) {
    echo $color . "<br>";
}
?>

⚙️ 6. Functions & Arrays Reusable Code

Create reusable functions and work with indexed or associative arrays.

<?php
function greet($name) {
    return "Hello, $name!";
}

$fruits = ["apple", "banana", "orange"];
array_push($fruits, "grape");
$count = count($fruits);

$person = ["name" => "John", "age" => 30];
echo $person['name'];
?>

🔤 7. Strings Text Handling

PHP has a huge library of built-in string functions.

<?php
$str = "syntaxlab";
echo strtoupper($str);
echo "<br>";
echo strlen($str);
echo "<br>";
echo str_replace("lab", "Lab", $str);
?>
Output:
SYNTAXLAB<br>9<br>syntaxLab

📝 8. Form Handling (GET/POST) User Input

Retrieve data from HTML forms using the $_GET or $_POST superglobals.

<form method="POST" action="process.php">
  <input type="text" name="username">
  <input type="submit">
</form>

<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $username = $_POST['username'];
    echo "Welcome, $username!";
}
?>

🗄️ 9. Working with Databases (PDO) MySQL Access

Connect to a MySQL database using PDO for safe, parameterized queries.

<?php
$pdo = new PDO("mysql:host=localhost;dbname=test", "user", "pass");

$stmt = $pdo->prepare("SELECT * FROM users WHERE id = ?");
$stmt->execute([$id]);
$user = $stmt->fetch();

$sql = "INSERT INTO users (name) VALUES (:name)";
$stmt = $pdo->prepare($sql);
$stmt->execute(['name' => $name]);
?>

🔐 10. Sessions & Cookies Maintaining State

HTTP is stateless — sessions and cookies let you remember users across page loads.

<?php
session_start();
$_SESSION['user_id'] = 123;

setcookie("theme", "dark", time() + 86400, "/");

if (isset($_SESSION['user_id'])) {
    echo "User is logged in";
}
?>

🏗️ 11. Object-Oriented PHP Classes & Objects

PHP fully supports object-oriented programming with classes, properties and methods.

<?php
class Student {
    public $name;
    private $grade;

    public function __construct($name, $grade) {
        $this->name = $name;
        $this->grade = $grade;
    }

    public function display() {
        return "{$this->name} scored {$this->grade}";
    }
}

$s = new Student("Alice", "A");
echo $s->display();
?>
Output:
Alice scored A

🌳 12. Inheritance extends

A child class inherits properties and methods from its parent using extends.

<?php
class Animal {
    public function speak() {
        echo "Animal makes a sound";
    }
}

class Dog extends Animal {
    public function speak() {
        echo "Dog barks";
    }
}

(new Dog())->speak();
?>
Output:
Dog barks

⚠️ 13. Exception Handling try / catch / finally

Gracefully handle runtime errors using try-catch blocks.

<?php
try {
    $result = 10 / 0;
    if (is_nan($result) || is_infinite($result)) {
        throw new Exception("Division error");
    }
} catch (Exception $e) {
    echo "Caught: " . $e->getMessage();
} finally {
    echo "\nDone.";
}
?>

📄 14. File Handling Reading & Writing

PHP provides functions like fopen(), fwrite() and file_get_contents() for working with files.

<?php
$file = fopen("data.txt", "w");
fwrite($file, "Hello PHP!");
fclose($file);

$content = file_get_contents("data.txt");
echo $content;
?>
Output:
Hello PHP!

🧰 15. Superglobals Built-in Arrays

PHP provides several built-in superglobal arrays accessible anywhere in your code, such as $_SERVER and $_GET.

<?php
echo $_SERVER['PHP_SELF'];
echo $_SERVER['REQUEST_METHOD'];
print_r($_GET);
?>
